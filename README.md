# Logan FIG Intelligence

Private brokerage-platform SEC Form 13F research application for Logan Capital FIG.

Scope: brokerage platforms, outside-manager disclosure analysis, growth ETF active-to-passive signals, and daily SEC filing checks. No insurance-company or pension-plan coverage.

Deployment is **not yet enabled**. The application must have authentication, verified SEC ingestion, tested database migrations, and Railway configuration before being exposed.

The working application source is currently maintained as a separate ZIP artifact pending import into this repository.
